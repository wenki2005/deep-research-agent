# 改善反馈与学习指引 · 2026-09-08

## 本轮交付

本轮实现了复查计划第 1、2 阶段的保守版本，并提前处理部分任务隔离问题。当前输出为“可追溯资料摘录报告”：模型负责检索和选取引文，代码只保留能够在本次来源中匹配的摘录。未经语义验证的模型长篇结论不再直接交付。

这项变化主动牺牲部分自由分析和标题多样性，防止“真实引文旁边附上虚构结论”。它没有实现自动语义事实核验。未来恢复详细分析时，必须把每个原子主张绑定到支持/矛盾/不足的判断，并经过标注集验证。

## 已实现

| 范围 | 行为 | 核心文件 |
|---|---|---|
| 报告正文 | 标题、摘要、建议、局限和无依据发现不再沿用模型草稿；保留原文摘录并明确归因 | routing.py |
| 引文 | 每个 URL 分别匹配，支持 SRC 编号；不存在的引文删除；匹配也只标为 reported_not_verified/low | routing.py、models.py |
| 来源元数据 | 标题与发布日期来自工具；不采纳模型 official 分类来打分；日期拒绝无效/未来值 | provenance.py、routing.py |
| 来源入口 | 搜索、新闻、抓取共用 URL 策略；搜索页/未解析搜索跳转不进入来源列表 | tools.py、provenance.py |
| 搜索兜底 | 清洗后无可引用结果才尝试下一后端；新闻空结果正常失败，缺 Key 也尝试兜底 | tools.py |
| 时间筛选 | any/day/week/month/year 统一枚举；Tavily 用 time_range，DDG 用 timelimit；Bing/Baidu 抓取无法保证时间过滤时显式拒绝，由自动链继续尝试 | tools.py |
| 正文与摘要 | Tavily 请求 raw_content；无正文则按搜索摘录处理，不能展示为已读全文 | tools.py、provenance.py |
| 运行隔离 | 移除进程全局注册表，工具通过每次运行的闭包绑定；异常/取消时恢复上下文；线程登记加锁 | provenance.py、tools.py、agents.py |
| 补证据 | 对原问题额外搜索一次，再限次重写；仅当候选结果质量提高时替换，异常保留首次结果 | runner.py |
| 评估 | 零证据不再通过；合理拒答独立统计；passed 仅代表摘录报告质量检查，不代表事实正确 | evals.py |
| 展示 | 界面解释“引文匹配覆盖率≠事实准确率”；原文标题/引用中的链接和 HTML 按文本处理 | formatting.py、app.py |
| 保存 | 保存用户原问题，并以随机后缀避免同秒同名报告覆盖 | runner.py、models.py |

引文匹配可以证明文本在捕获资料中出现；它不能证明来源本身真实，也不能证明原先模型的主张成立。当前程序不会把模型输出自动升级成 confirmed。

## 每步学习内容

1. **来源入口统一**：阅读 tools._clean_results、_search_raw、_news_search。重点理解“原始结果非空”和“有效文章结果非空”的差别。试着将第一个模拟后端换为只有搜索页，观察第二个后端继续执行。
2. **来源注册与隔离**：阅读 ProvenanceRegistry、use_registry、isolated_run、bound_tools。重点理解 ContextVar、线程传递、闭包绑定与 finally 恢复，不能依赖全局变量替代任务状态。
3. **证据闸门**：阅读 apply_provenance_guard 与 test_all_draft_prose_removed_and_contradictory_claim_not_certified。思考为什么相反结论也能引用同一句原文；当前策略只交付摘录。
4. **评估契约**：阅读 score_case。结构齐全、引文匹配、合理拒答、事实正确是不同的指标。不能通过强迫每次生成长报告来提高质量得分。
5. **重试质量**：阅读 report_quality 与补证据分支。重试应增加资料，失败时保留已完成成果；不要无条件用最后一次输出覆盖前一次。

## 下一阶段建议

1. 保存来源快照、抓取时间、正文哈希、引文偏移和校验原因，形成可重放证据包。
2. 基于快照增加主张—证据语义判断和人工复核；充分验证前，不恢复自由生成的已确认结论。
3. 做 30 道人工标注题、每题 3 次，包含否定报道、同名实体、历史事件、无答案和转载；比较质量、拒答率、耗时与成本。
4. 单独核验真实热点检索召回。搜索页过滤目前采取保守策略，未解析的搜索跳转会被丢弃；后续应安全解析并核验最终正文地址。
5. API 任务队列、总超时/取消、记忆有效期和来源独立性仍在后续计划。当前只有 quoted 摘录报告可以入记忆，但引用齐全不代表内容真实，历史记忆仍只能作线索。
